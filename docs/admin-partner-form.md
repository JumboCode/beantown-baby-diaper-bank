# Admin Partner Form – Quick Fill Guide

Use this guide to quickly create a partner in the Admin > Partners page ("Add A New Partner").

## Required fields

1. **Name of Organization**
   - Example: `Playwright Test Partner`

2. **Description**
   - Example: `Created by Playwright for admin flow test.`

3. **Cities Served**
   - Type a city (e.g., `Boston`), press **Enter** to add.
   - In the **Cities Percentage** table, set the percentage for each city.
   - Example: `Boston` → `100%`.

4. **Time it started**
   - Click **Pick date**.
   - Select **Month** and a **day** (if the calendar opens at the month view, click the month to open the full calendar).

5. **Status**
   - Choose **Active**, **Inactive**, or **Waitlisted**.

6. **Coords**
   - **Latitude** (e.g., `42.3601`)
   - **Longitude** (e.g., `-71.0589`)

7. **Address**
   - **Address Line** (e.g., `1 Test Street`)
   - **City** (e.g., `Boston`)
   - **State** (e.g., `MA`)
   - **Zip Code** (e.g., `02108`)
   - **Country**: type and select from dropdown (e.g., `United States`).

## Optional fields

- **Logo file or link**
  - Upload an image or paste a **Logo URL**.

## Submit

- Click **Submit**.
- Verify the new row appears in the Partners table with the correct values.

## Common gotchas

- **Country must be selected** from the dropdown; typing alone may not be enough.
- **City percentage** must sum to **100%**.
- If **Submit** does nothing, check for missing required fields.
